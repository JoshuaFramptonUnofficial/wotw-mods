# Frampton’s WotW Mods

War of the Worlds: Red Horizon mods by **@framptonbtw**.

## Mods

Bringing back the original 2005 tripods for War of the Worlds: Red Horizon.

The current version, game build requirements, install steps and previous versions
are on the website: https://joshuaframptonunofficial.github.io/wotw-mods/
Downloads are under Releases.

Back up your saves before installing or updating a mod. Multiplayer players need
identical mod files and the same game build.
