# Frampton’s WotW Mods

War of the Worlds: Red Horizon mods by **@framptonbtw**.

## 2005 Tripod

Original 2005 tripod model, vfx and sounds. Version **1.1.1** supports Windows x64
and game build **26369083**. The game’s stock probe is retained.

Download the mod ZIP from Releases. Close the game, back up your saves and mod
settings, then extract the ZIP into the main game directory beside
`War of the Worlds.exe`. Enable **2005 Tripod** in the main-menu Mods screen.
The ZIP includes updating, save and removal instructions.

Both multiplayer players need identical mod files and the same game build.
